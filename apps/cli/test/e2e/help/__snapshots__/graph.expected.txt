Usage: symnav graph [options] <target>

Show call paths around a symbol

Options:
  --line <n>       narrow target matches to declarations containing this line
  --regex          match full canonical symbol ids by JavaScript regex (default: false)
  --incoming       show caller paths only (default: false)
  --outgoing       show callee paths only (default: false)
  --depth <n>      maximum call depth
  --page <n>       page of graph paths to show
  --page-size <n>  graph paths per page
  --all            show every graph path on one page (default: false)
  --json           emit JSON instead of text (default: false)
  -h, --help       display help for command
